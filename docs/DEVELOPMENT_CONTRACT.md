# Integration contract

Project root: `/workspace/Catch-Me-If-You-Can`. Rojo maps `src/shared` to ReplicatedStorage.CatchShared; `src/server` to ServerScriptService.CatchServer; `src/client` to StarterPlayer.StarterPlayerScripts.CatchClient. Use require(script.Parent...) within own subtree and ReplicatedStorage:WaitForChild("CatchShared") across trees. Standard R15 avatars, 12-player limit; no gameplay asset IDs required.

Every service exposes `Module.new(ctx)` and optional `:Start()`. ctx contains Config, Catalog, Rules, Remotes, World, Services. All services are constructed before Start. Root bootstraps them. Do not create Bootstrap files outside your ownership.

Remotes under ReplicatedStorage.CatchRemotes: `State`, `Action`, `Profile`, `Notice` RemoteEvents; `Query` RemoteFunction. Root makes them. State sends a full public round snapshot. Profile sends a full safe player snapshot. Notice payload `{kind="toast"|"tag"|"round"|"purchase"|"level"|"unlock"|"ability", text?, position?:Vector3, userId?, action?, cooldown?}`. Query returns `{state=RoundService:Snapshot(), profile=DataService:Snapshot(player)}`. Client sends `Action:FireServer(action, payload)`; root validates envelope and rate limits before dispatch.

## Catalog (root owns)

Each entry `{id, category, name, description, currency="Free"|"Coins"|"Robux"|"Milestone",price,gamePassId=0,rarity="Common"|"Rare"|"Epic"|"Legendary",accent={r,g,b}, milestone?={stat="level"|"wins"|"tags",value},grants?={ids...}}`. Category strings: skins,masks,trails,tagEffects,victories,emotes,nameplates,bundles,vip. Catalog.Categories ordered list of `{id,label}`. Catalog.DefaultEquipment={skins="skin_courier",masks="",trails="",tagEffects="tag_spark",victories="victory_wave",emotes="emote_wave",nameplates="name_rookie"}. Catalog.Get(id), Catalog.ForCategory(category), Catalog.IsEquippable(category), Catalog.DefaultOwned(). ## Rules (root owns, pure Luau)
Rules.HunterCount(count) returns 0 if <2; 1 if 2..6; 2 if 7..12. Rules.LevelFromXP(xp), Rules.XPForLevel(level) cumulative; Rules.Rank(rating) string. Rules.NewProfile(now?) produces profile schema below. Rules.NormalizeProfile(raw,now?) sanitizes persisted data. Rules.RoundReward(summary, config) => {xp,coins,rating}; practice => zero. Rules.DailyQuests(dayKey) ordered definitions `{id,text,stat,goal,xp,coins}` with IDs play_3, tag_5, survive_120. Rules.DayKey(timestamp) UTC yyyy-mm-dd. Rules.QuestProgress(profile,quest).

Profile: `{schemaVersion=1,coins=0,xp=0,level=1,rating=1000,streak=0,bestStreak=0,stats={rounds=0,wins=0,hunterWins=0,runnerWins=0,tags=0,survived=0},owned={id=true},equipped={category=id},settings={music=true,sfx=true,reducedMotion=false,cameraShake=true},daily={day="",progress={rounds=0,tags=0,survived=0},claimed={}},achievements={}}`. Snapshot adds `{loaded=true, persistence="saved"|"session"|"unavailable",rank,quests=[{id,text,progress,goal,claimed,xp,coins}],saveMessage?}`; never claim a write succeeded until it did. Client does not receive session lock metadata.

## Service APIs
- DataService: `:Get(player)`, `:Ready(player)`, `:Snapshot(player)`, `:Send(player)`, `:AwardRound(player,{role="Hunter"|"Runner",win,tags,survived,practice,roundId})`, `:Grant(player,ids,source)`, `:Equip(player,category,id)` (id="" unequips), `:UpdateSettings(player,settings)`, `:ClaimQuest(player,id)`, `:Save(player)`. Lifecycle handles loading and binds close. Cosmetics call after equip via ctx.Services.CosmeticService:Apply(player). Award only once per roundId. Never award practice progression.
- ShopService: `:Purchase(player,id)`, `:Start()`. Server validates gamepass ownership; IDs zero disable prompt with clear notice; no invented products. Coins purchase server validates amount and ownership. Refresh owned passes on join.
- RoundService: `:Snapshot()`, `:GetRole(player)` => "Hunter"|"Runner"|"Spectator"|"Lobby"; `:IsActive(player)`; `:TryTag(player)`; `:Start()`. Movement uses roles. State snapshot `{phase="Waiting"|"Intermission"|"HeadStart"|"Active"|"Results",endsAt=workspace:GetServerTimeNow()+remaining,roundId=number,practice=boolean,finalChase=boolean,lastRunner=boolean,aliveRunners=number,players=[{userId,name,displayName,role,alive}],winners=[userId],resultText=string,mapName="NEON HEIGHTS"}`. Per-player role from players array. Solo Studio practice uses Runner, no victories or farmable rewards, clear state. Map remains playable for 180s/restart. Watch spectators are eliminated or midround joins. Character death/reset eliminates; joins don't alter round roster. Players load before eligible. `TryTag` server range, line of sight, live role, cooldown. Head start hunters held server-side. End at no runners or deadline; hunter departure gives runner win; cleanup all characters/attributes.
- MovementService: `:Handle(player,action,payload)` for Sprint {active},Slide {},Vault {}; `:Start()`. Server validates cooldown, role, alive, grounded/raycast/geometry and speed/distance. Client never specifies movement speed/position. Set attributes Sprinting,Sliding,Vaulting on character; adjust speed. Anti teleport enforcement with explicit trusted teleports from `:ResetPlayer(player)` called after round/lobby spawn; motion exemptions bounded. Root dispatches Tag to RoundService.
- CosmeticService: `:Apply(player)`, `:Preview(rig,skinId,maskId,extra?)` optional, `:ShowWinners(players)`; `:Emote(player,id)` validates equipped/owned and lobby/results; `:Start()`. It can expose Shared/Appearance.lua for client ViewportFrame and server. User identity preserved. Distinct skin silhouette pieces attach to standard R15 limbs; masks independent. No paid gameplay attributes. Clear generated accessories on reapply.
- MapBuilder.Build() => `{Model,LobbySpawn:CFrame,RunnerSpawns:{CFrame},HunterSpawns:{CFrame},Podiums:{CFrame},Bounds={min:Vector3,max:Vector3}}`. Build once. Map geometry must allow navigation via ramps/stairs/ladders and bridges; no asset ID dependencies. Any dynamic obstacles own limited loop and never trap main paths. Map content ownership src/server/World only.

## Client controllers
Module.new(ctx), :Start(). ctx={Config,Catalog,Rules,Remotes,State={},Profile={},Controllers={},Signals={}}. Root handles Query, State, Profile, Notice, CharacterAdded. Root calls controller `:OnState(state)`,`:OnProfile(profile)`,`:OnNotice(notice)` if available AFTER state assign; :Start called first. UI can query ctx.State/Profile on Start. Root periodic Query until loaded. Controllers must clean per-character connections. No root Bootstrap files.
- MovementController owns input ContextActionService sprint/slide/vault/tag, touch buttons, controller bindings; sprint FOV and optional camera offset/bob, animation motor transforms bounded. Handles :OnState/:OnNotice optional. Server authority; show cooldown only on server acknowledgment. Tag input plus auto intent when near target optional. Client must not create movement speed bypass. Use Shift / C / Space vault attempt / F tag; gamepad L3/B/A/R2. Preserve normal jump. Reduced motion honored via ctx.Profile.settings. Own src/client/Controllers/MovementController.lua and EffectsController.lua.
- UIController owns ScreenGui, lobby/main/loading, live HUD, Shop/Inventory with categories and ViewportFrame using shared Appearance (cosmetics agent provides), quests/progression/settings/results/spectating. Spectate camera when role Spectator and Active/HeadStart; recover on next round/respawn; native camera movement controller must not fight it. Queries and events through ctx. Buttons use Action; Buy {id},Equip {category,id},ClaimQuest {id},Settings allowed bools,Emote {id}. Use catalog prices/configured state; "Not configured" for gamePassId=0; account for returned server statuses. Responsive layouts. Desktop + touch + gamepad selectable. Owned values server-driven. Own src/client/Controllers/UIController.lua only.

## Ownership
Root: Shared Config/Catalog/Rules, bootstraps, Rojo config, tooling/tests/docs/review. Gameplay agent: RoundService + MovementService. World agent: MapBuilder. Data agent: DataService + ShopService. Cosmetics agent: CosmeticService + src/shared/Appearance.lua. Client movement agent: MovementController + EffectsController. UI agent: UIController. Coordinate conflicts via root. All implementation goes in existing checkout; no worktrees.
